Known Bugs, Shortcuts, and Unfinished Work

2. Current Technical Shortcuts

Single-Page Architecture
The original website uses one HTML page and JavaScript to switch between its main sections.


JavaScript-Based Content
Timeline events and team information are stored in JavaScript arrays.
The original application does not retrieve this information from an Express API.


Image Handling

The image carousel supports image paths stored in the team objects. 
Real photographs and correctly maintained image paths still need to be added.
